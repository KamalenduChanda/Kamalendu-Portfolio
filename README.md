# Kamalendu Chanda — Official Portfolio Website

Welcome to the official creative portfolio website for **Kamalendu Chanda**, Motion Graphic Designer & Video Editor based in Kolkata, India.

## 🌟 Overview
A dynamic, high-performance web experience showcasing high-end motion design, cinematic narrative editing, commercial key art, photo manipulation, packaging design, and 3D social campaigns.

- **Creative Domains**:
  - Motion Design & 2.5D Multiplane Parallax Compositing
  - Cinematic Video Editing & Sound Design
  - Digital Matte Painting & Fantasy Photo Manipulation
  - Vector Identity, Kinetic Logos & Packaging Design
  - Commercial Advertising, Theatrical Key Art & 3D Social Media Mockups
- **Core Software Stack**:
  - Adobe After Effects
  - Adobe Premiere Pro
  - Adobe Photoshop
  - Adobe Illustrator
  - Generative AI

## ⚡ Technical Features
- **Dynamic 2.5D Parallax Hero**: Multi-plane depth separation with organic mist drift, responsive cursor depth, and procedural ambient light particles.
- **Interactive Multi-Tool Filtering**: Instant project filter system by software (`All`, `Ae`, `Pr`, `Ps`, `Ai`, `Gen AI`) with dynamic count badges.
- **Adaptive Project Modal & Gallery**:
  - Deep-dive project breakdowns detailing software execution, technical pipelines, and deliverables.
  - Responsive gallery grids displaying models and variants without vertical letterboxing.
- **Master 100% Full-Resolution Lightbox Viewer**:
  - **1:1 Native Resolution Zoom**: Seamlessly inspect fine brushwork, bubbles, droplet textures, and vector details.
  - **Interactive Drag & Pan**: Click-and-drag navigation across 100% scaled master files on desktop.
  - **Mobile Touch Gestures**: Tap-to-zoom and swipe left/right navigation optimized for Android and iOS browsers.
  - Direct "Open Raw" button to view uncompressed master artwork in full screen.
- **Interactive Showreel Player**: Integrated video player with chapter scrubbing, custom controls, and direct YouTube integration.

## 🚀 Deployment & Local Usage
Clone the repository:
```bash
git clone https://github.com/KamalenduChanda/Kamalendu-Portfolio.git
```
Open `index.html` in any modern web browser, or host via **GitHub Pages** (`Settings` > `Pages` > select `main` branch).
